Modelo Paramétrico de Edificaciones

La programación permite crear modelos paramétricos y algoritmos de optimización que manejan geometrías complejas con total flexibilidad. Esto no solo acelera radicalmente el proceso de modelado, sino que garantiza modelos consistentes y libres de errores tipográficos.

Generación de edificaciones paramétricas completas utilizando la API CSI ETABS y Python, permitiendo al usuario modificar instantáneamente parámetros geométricos, mecánicos y solicitaciones.

Con este flujo automatizado se optimiza más del 90% de las fases preliminares de modelado:

  • Definición de materiales estructurales (concreto, acero, albañilería).
  • Creación de casos y patrones de carga estáticos y dinámicos.
  • Generación de combinaciones de carga según norma técnica.
  • Asignación de cargas distribuidas y concentradas.
  • Replicación inteligente de elementos tipo shell, diafragmas rígidos y vigas.
  • Ejecución de análisis modal espectral y verificación de derivas.
