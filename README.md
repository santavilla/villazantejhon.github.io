## Contenido del Portafolio

1. **Modelado BIM & Cobertura Metálica (Autodesk Revit):** Modelado tridimensional de arco reticulado metálico sobre polideportivo, planos de planta con modulación de ejes y láminas de detalle constructivo (apoyos, placas base y anclajes con pernos "J").
2. **Automatización del Análisis Sísmico (Norma E.030):** Extracción automatizada de matrices y derivas desde ETABS hacia memorias de cálculo y gráficos dinámicos en Python.
3. **Modelo Paramétrico de Edificaciones:** Generación automatizada de estructuras completas en ETABS vía OAPI (materiales, patrones de carga, combinaciones sísmicas, réplicas y shells).
4. **Gráficos de Dinámica Estructural:** Curvas de histéresis, método paso a paso de Newmark (1GDL y MGDL), vibración libre y simulación de péndulos amortiguados.
5. **Análisis No Lineal (Pushover & STERA 3D):** Curvas de capacidad, fibras y rótulas plásticas, análisis incremental de edificios de concreto armado.
6. **Tratamiento de Señales Sísmicas:** Procesamiento de acelerogramas del Sismo de Pisco 2007 (Estación UNICA) y cálculo de espectros elásticos de pseudoaceleración.
7. **GeoDatos & Zonificación Sísmica:** Análisis espacial y mapas interactivos con ArcGIS, GeoPandas y capas GeoJSON.
8. **OpenSeesPy (2D & 3D):** Análisis computacional de pórticos planos, espaciales y armaduras con cálculo matricial de deformadas y modos de vibración.
9. **Diseño Sísmico & Diagrama de Interacción P-M:** Columnas rectangulares de concreto armado bajo el código ACI 318 y Norma E.060 implementado en Jupyter Notebooks.
10. **Plantillas y Memorias de Cálculo Automatizadas:** Zapatas aisladas, vigas, columnas, muros de contención y albañilería confinada (E.070).
11. **Desarrollo de Software Propio, Plugins & Complementos — MJJ Suite:**
    - **Estructural & Cálculo:** EstructurasPro Python, MJJ SectionPro, MJJ STRUCTURAL WP, MJJ UTILITARIOS.
    - **Gestión de Obra & Expedientes:** SISTEMA ALMACEN DE OBRA (AlmacénPro), MJJ PANEL FOTOGRAFICO, MJJ Metrados, MJJ METRADOS SOFT, MJJ ExpTech, COMPLEMENTO EXCEL FOLIAR.
    - **Topografía, CAD, GIS & Urbanismo:** MJJ GeoCAD, MJJ MAPS ARC, DIBUJO CAD, Plugin CAD CRZ, MJJ LOTIZA CD, PREDIO_V3.

## Cómo publicar este portafolio en GitHub Pages

Para publicar tu portafolio en vivo como `https://villazantejhon.github.io/`:

```bash
git init
git add .
git commit -m "feat: portafolio profesional estilo GitHub Pages Minimal"
git branch -M main
git remote add origin https://github.com/villazantejhon/villazantejhon.github.io.git
git push -u origin main
```

*(Si usas un repositorio con otro nombre, la URL será `https://villazantejhon.github.io/nombre-del-repo/`).*

### Activar GitHub Pages en el repositorio:
1. Ve a tu repositorio en GitHub: `https://github.com/villazantejhon/villazantejhon.github.io`
2. Ve a **Settings** > **Pages** (en el menú lateral izquierdo).
3. En **Branch**, selecciona `main` y `/ (root)`.
4. Haz clic en **Save**. En un par de minutos tu sitio estará en línea.
